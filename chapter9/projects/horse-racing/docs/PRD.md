# Derby Day — product brief

## 목적
브라우저에서 반복해서 즐기는 단일 플레이어 경마 베팅 게임. 가상 크레딧만 사용하며 실제 결제나 현금성 가치는 없다.

## 사용자 흐름
로비에서 경주마와 배당률을 확인하고 단승 베팅을 한다. 베팅 후 3초 카운트다운, 8~15초 경주, 결과 오버레이 정산을 거쳐 자동으로 다음 로비로 돌아간다.

## 게임 규칙
- 기본 참가마 5마리, 설정 범위 4~8마리.
- 회차별 스탯은 소폭 변하고 능력치를 기준으로 소수점 배당률을 산정한다.
- 말마다 고유 스킬 1개, 회차당 1회 사용. 후미 주자일수록 발동 확률이 높다.
- 초반 최하위 말의 우승 역전극 비율은 10~20%를 목표로 조정한다.
- 단승(우승마 한 마리 선택)만 제공한다. 베팅 금액은 잔고 범위 내에서 설정한다.
- 시작 잔고는 1,200 CR이며 잔고가 최소 베팅액 10 CR보다 적어지면 1,200 CR로 자동 재충전한다.

## 화면 및 연출
- React + Canvas 2D, 기준 캔버스 1350×690, 반응형 축소.
- 관중석, 출발 게이트, 체크무늬 결승선, 다리 애니메이션이 있는 경주마 실루엣, 기수, 번호 안장보.
- 먼지와 속도선, 스킬 오라와 이름 배너, 막판 슬로모션/카메라 흔들림, 우승 배너/스포트라이트/연속 폭죽.
- 경기 중 실시간 순위표와 실황 자막. 정산은 경주 화면 위 오버레이로 표시한다.
- Web Audio 효과음과 음소거 토글. 말은 모든 곳에서 번호와 이름을 함께 표기한다.
- 사용성: 데스크톱 우선, 작은 화면에서 패널이 쌓이는 반응형 레이아웃. 키보드 포커스와 충분한 명도 대비.

## 저장 및 기술
- Vite + React + TypeScript, 순수 난수 주입형 경주 로직.
- localStorage에 잔고, 전적, 음소거와 참가마 수 저장. 저장 자료가 손상되어도 기본값으로 복구한다.
- 외부 서버/API, 계정, 실결제 없이 동작한다.

## 검증
- 경주 결과, 역전률, 배당, 정산, 재충전, 저장 로직의 자동 테스트.
- 실제 브라우저에서 베팅부터 경주/정산/로비 복귀까지 실행하고 스크린샷으로 레이아웃을 확인한다.

## 미해결 의사결정
- 베팅 방식은 사용자 답변에 따라 단승만으로 확정한다.
- 역전 주행 목표는 15%로 두고 시뮬레이션 테스트에서 10~20% 범위인지 확인한다.
