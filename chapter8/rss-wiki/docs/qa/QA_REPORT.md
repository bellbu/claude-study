## 5. 검증 범위 밖

- **실제 Claude 모델의 출력 품질**: API 키가 없어 Mock Claude로 검증했습니다. 요청 형식(모델 이원화, `output_config.format` JSON 스키마, 시스템 프롬프트 캐시, Sonnet `fallbacks`/beta 헤더)과 응답 처리·검증·재시도 흐름은 실제 SDK의 HTTP 경로로 확인했지만, 실제 모델이 내는 요약·분류·재작성의 품질은 확인하지 못했습니다. 실제 키로 피드 몇 개를 1주일 정도 돌려 보며 확인해야 합니다(PRD 9장 성공 지표).
- **실제 비용**: 비용 계산과 상한 차단은 Mock 토큰 수로 확인했습니다. 실제 사용량은 운영해 보며 확인해야 합니다.
- **실제 외부 RSS 피드**: 로컬 픽스처 피드만 사용했습니다. 다양한 실제 피드 형식(Atom, 인코딩 문제, 대용량 본문)은 운영 중 확인이 필요합니다.
- **스케줄러 정시 실행**: 트리거 설정과 재설정은 단위 테스트로 확인했고, 실제로 06:00에 실행되는 것은 확인하지 않았습니다.
