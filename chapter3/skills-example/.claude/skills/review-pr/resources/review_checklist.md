# PR Review Checklist
## 코드 품질
- [ ] 네이밍이 명확한가?
- [ ] 중복 코드가 없는가?
- [ ] 함수와 컴포넌트가 과도하게 길지 않은가?
## 로직 및 에러 처리
- [ ] 빈 값, null, 경계값 처리가 되어 있는가?
- [ ] 실패 경로와 예외 처리가 적절한가?
## 보안
- [ ] 하드코딩된 시크릿이 없는가?
- [ ] 사용자 입력 검증과 인젝션 방어가 되어 있는가?
## 성능
- [ ] 불필요한 반복문이나 N+1 호출이 없는가?
- [ ] 대용량 처리에서 메모리 사용을 고려했는가?
## 테스트와 문서
- [ ] 새 동작에 대한 테스트가 있는가?
- [ ] 공개 API나 사용법이 바뀌었다면 문서가 갱신되었는가?
