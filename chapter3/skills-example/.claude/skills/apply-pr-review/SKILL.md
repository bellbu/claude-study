# GitHub PR Feedback Applier Skill
## Goal
PR 리뷰 피드백을 누락 없이 처리하고, 수정 사항을 커밋한 뒤 각 코멘트에 구체적으로 응답합니다.
## Instructions
1. PR 번호가 있으면 `$ARGUMENTS`를 PR 번호로 사용합니다. 없으면 현재 브랜치의 PR을 확인합니다.
2. `gh pr view <PR번호> --json reviews,comments`로 일반 코멘트를 확인합니다.
3. `gh api repos/{owner}/{repo}/pulls/<PR번호>/comments`로 라인 리뷰 코멘트를 확인합니다.
4. 코멘트를 `수정 요청`, `질문`, `제안`, `확인/칭찬`으로 분류합니다.
5. 수정 요청과 적용할 제안은 코드 변경 계획을 먼저 보여주고 사용자 승인을 받습니다.
6. 승인된 변경만 적용하고 테스트를 실행합니다.
7. 커밋이 필요하면 `git-commit` 스킬의 형식을 따릅니다.
8. 각 코멘트 응답 초안을 보여주고 승인 후 제출합니다.
## Reply Guide
- 무엇을 어떻게 수정했는지 구체적으로 설명합니다.
- 동의하지 않는 제안은 이유와 대안을 정중히 적습니다.
- 모든 코멘트에 응답하거나, 응답하지 않는 이유를 명시합니다.
좋은 예: "N+1 가능성을 줄이기 위해 `selectinload`를 적용했고, 관련 테스트를 추가 했습니다."
나쁜 예: "수정했습니다."
